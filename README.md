# 游艺小馆 · 小游戏集合

一个持续扩展的网页小游戏集合。游戏以独立目录组织，静态内容可以直接部署到 GitHub Pages。

## 已有游戏

### 绮局：中国象棋

- 完整象棋棋规与将军、将死判定
- 简单和噩梦两档纯浏览器 AI
- Q 版合成音效、炮击提示与战斗演出
- 随机匹配、服务器权威判定、计时、认输、再战和断线重连

噩梦 AI 在 Web Worker 中运行，使用紧凑 90 格棋盘、增量 Zobrist 哈希、跨回合置换表、PVS、Alpha-Beta、静态延伸、空着裁剪、后期着法缩减、杀手着法和历史启发。无需模型文件或 AI 接口。

### 星盘：五子棋

- 标准 15×15 星盘与自由五子棋规则
- 简单、噩梦两档浏览器 AI，计算过程运行在 Web Worker
- 本地双人、悔棋、键盘落子、胜利连线与 Q 版合成音效

### 叠数坊：2048

- 标准 4×4 合并规则、分数与本地最高纪录
- 键盘、WASD 与触屏滑动控制
- 单步撤销、2048 达成提示及继续挑战

### 青竹游：贪吃蛇

- 三档速度、逐级加速与暂停
- 键盘、WASD、触屏滑动和方向按钮
- Q 版蛇头、桃子食物与本地最高纪录

### 三国·山河志：轻量长期 SLG

- 36 座城池、10 个可选势力、60 名武将的月度长期战役
- 内政建设、征兵训练、城防、出征、自动战斗与势力覆亡
- 独立军团编制：主副将、兵力、携粮、逐月行军与地图军旗
- 野战、强攻、长期围城、援军解围、撤退、驻扎和归营
- 粮道与军粮消耗；断粮会降低士气并产生逃兵
- 动态武将状态：在仕、在野、被俘、归降、忠诚与功勋
- 城内访贤和厚礼延揽；低忠诚武将可能离心下野
- 阵前擒将、劝降或释放俘虏，AI 也会招募人才和招降俘将
- 武将专属技能，以及将军、军师、尚书等官职加成
- 可任命不同太守，武将能力与技能会影响城市收入和政令效果
- 馈赠、同盟、威压等外交行动，以及关系与国力判定
- 太守委任可自动补强城池，降低中后期重复操作
- v0.4 战略 AI：边境防守、集中兵力、盟友救援、避强击弱与季度目标
- v0.5 限时停战/同盟、共同进攻、离间、策反与反间
- v0.6 科技树、五种国策、城市特产、灾害与人口迁移
- v0.7 群雄割据、官渡风云、赤壁鏖兵三个剧本，历史事件、统一评价与战役统计
- v0.8 新手引导、战役回放、三个本地存档槽、1/3/6 月速度控制与移动端适配

### 苔光邮局：治愈系小岛探索

- 原创低多边形小岛场景，包含邮局、温室、睡莲池、菜圃与潮汐栈桥
- WASD、方向键、点击寻路与移动端虚拟方向键
- 送信、每日采集、天气加成、体力、昼夜光影和本地自动存档
- 完整短篇任务线：收集星露、修复观星镜与重建栈桥
- 手账式任务界面、发光邮路导航、NPC 对话与结局演出

### 蘑菇堡保卫战：Q 版像素塔防肉鸽

- 独立于三国 SLG 的西幻守城游戏，支持桌面和手机浏览器
- 小骑士、小弓手、小法师三种职业，可部署、升级与撤回；相邻职业形成菌丝连锁
- 六波战役会逐步引入飞行、护甲、断丝敌人和狂暴 Boss，开战前可查看敌情
- 冒险者和五种敌人采用统一的 Q 版像素素材，带悬浮、踏步、受击与断丝反馈
- 每波三选一祝福，包括穿透箭、碎冰咒、孢子壁垒等改变打法的能力
- 流星术、倍速和暂停，最高战绩保存在浏览器本地

## 项目结构

```text
dist/
├─ index.html                # 游戏集合首页
├─ collection.css
└─ games/
   ├─ xiangqi/              # 中国象棋
   ├─ gomoku/               # 五子棋
   ├─ 2048/                 # 2048
   ├─ snake/                # 贪吃蛇
   ├─ three-kingdoms/       # 三国长期 SLG
   ├─ mosslight/            # 苔光邮局探索游戏
   └─ mushroom-keep/        # Q 版像素塔防肉鸽
server.mjs                  # 静态服务与联网匹配服务器
tests/                      # 棋规和 AI 测试
```

后续游戏建议统一放在 `dist/games/<game-name>/`，并在集合首页增加入口卡片。

## 本地启动

```powershell
npm start
```

打开 <http://127.0.0.1:4173/>。联网模式可用两个分别新开的浏览器标签页测试。

```powershell
npm test
```

## GitHub Pages

仓库自带 `.github/workflows/pages.yml`。推送到 `main` 后，GitHub Actions 会发布 `dist`。

人机模式和单机内容在 GitHub Pages 上可以直接运行。随机联网匹配依赖 WebSocket 服务，正式上线时需要单独部署 `server.mjs`，再让前端连接该服务。

## 局域网对战

```powershell
npm run start:lan
```

另一台设备访问 `http://这台电脑的局域网IP:4173/`。联网房间保存在内存中，重启服务会清空排队与对局。
